# EditExpress Website

Dark luxury landing page for a social media reel editing and content creation brand.

## Features
- Premium black / purple / red theme
- Hero section with reel-focused messaging
- Services, portfolio, pricing, reviews, and CTA sections
- Mobile responsive navigation
- Contact details included

## Open locally
Open `index.html` in a browser, or run a local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
